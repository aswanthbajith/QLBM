# Quantum dam-break research extension — milestone 1

**Status: tested encoding and transport prototype, not a completed dam-break solver.** The upstream repository is preserved, and this directory is a new standalone research experiment. No real quantum device was used. Qiskit and Aer were unavailable in the build environment; optional Qiskit circuits are supplied but not yet executed. NumPy simulates exact statevector gates and the reduced density matrix of an explicit ancilla-assisted quantum channel. It does not evolve a separate classical fluid field or prepare a new state from a classical solver at each step.

## Run

From this directory with Python 3.10+:

```bash
python -m pip install numpy pytest
python -m pytest -q tests
python run_demo.py
```

Open `01_quantum_encoding_and_transport.ipynb` in Jupyter (kernel with NumPy installed). Open `results/step_000.vti` as a time series in ParaView, select `depth_proxy_m`, or inspect ASCII arrays directly. The results included in the archive were actually generated by `run_demo.py`. To use the native QLBM bridge, install the original project according to its root README and install compatible Qiskit/Aer. Then run `python -m pytest -q tests/test_qiskit_optional.py`. These optional tests were skipped in this environment; any incompatibility is a blocker to reuse, not evidence of circuit correctness.

## Encoding and circuit operations

The state uses QLBM's binary ordering: x least significant, then y, then 4 direction bits. A 4x4 grid uses 8 base qubits; the upstream lattice may also allocate geometry ancillas. We set `f_i = h w_i` at initialization, with nonnegative D2Q9 weights. The prepared ket has amplitude `sqrt(f_i/M)` for each valid position-direction state, where `M = sum(f_i)`. The seven unused velocity codes are never populated from the supported initial state. Depth is reconstructed by summing populations. The first velocity moment is a transport moment, not a validated fluid velocity. `dx = 1 m`, `dt = 1 s` are illustrative units, not calibrated water parameters. The encoded volume is `M dx^2`. Grid cells on the left start at 1 m; the right is dry with one solid obstacle. The solid mask and closed domain remain fixed.

The closed-streaming unitary is a bijective basis permutation: a link entering a solid or exiting the domain reverses direction at the source. Each basis transposition compiles into fully controlled X gates along a Gray path. Tests compare the gate-by-gate statevector simulation to the permutation action. This is a new small-grid operator, not a claim that upstream obstacle circuits were executed. Native periodic streaming and joint measurement are exposed through `qiskit_bridge.native_components`, directly importing the existing classes. The demonstration uses the new closed-boundary operator instead.

The dissipative demonstration uses a coin rotation with reset probability omega, a fresh velocity register in `sum sqrt(w_i)|i>`, four controlled swaps, and discards/resets the coin and fresh register. Its exact reduced channel is

`rho' = (1-omega) rho + omega (|w><w| tensor Tr_velocity(rho))`.

This channel preserves trace and position population during collision and relaxes directional momentum toward zero, but does NOT conserve local momentum or solve nonlinear BGK. Combined with streaming it models kinetic redistribution/diffusion, not shallow-water pressure waves. Do not infer viscosity or use these files as dam-break validation. Reset is nonunitary; quantum operations are not restricted to isolated unitary gates if ancilla disposal/measurement is allowed. The optional circuit uses 5 extra qubits for this channel.

## VTK fields

- `depth_proxy_m`: exact probability-derived depth using the initial normalization.
- `transport_moment_m_s`: velocity moment of the encoded populations (not verified hydrodynamic velocity).
- `position_probability`: exact marginal.
- `sampled_position_counts`: 4096 synthetic measurement samples per step from the simulated Born distribution, not hardware counts.
- `solid_mask`: fixed geometry.

The timestep sequence is collision/reset then closed streaming. The output includes exact fields and sampled counts separately. A fixed shot total is not proof of physical mass conservation; this experiment conserves encoded normalization by construction. `diagnostics.csv` records trace, depth proxy volume, solid population and measurement error.

## Remaining scientific work / acceptance gates

| Mechanism | Status | Acceptance criterion |
|---|---|---|
| Position/direction encoding and joint readout | Tested in NumPy | Exact reconstruction; shot convergence |
| Streaming/closed reflection | Tested in NumPy | Reversible mapping, no obstacle leakage; cross-check native gates in Qiskit |
| Ancilla-assisted reset | Tested in NumPy | Trace positivity; optional Qiskit density-matrix parity |
| Physical collision | Open | Local mass and momentum conserved; correct equilibrium, viscosity and positivity |
| Pressure and gravity | Open | Correct shallow-water flux and hydrostatic balance; no double-counting pressure |
| Physical dissipation | Open | Viscosity/friction derived from model, benchmark decay |
| Wet/dry interface | Open | Positivity, dry-front speed, lake-at-rest and volume tests |
| Integrated quantum dam break | Open | Compare independent classical solution, convergence and resource estimates |

First select one precise shallow-water D2Q9 discretization with a verified pressure equilibrium and admissible nonnegative populations, or change encoding. Classical benchmark is independent, not used to advance quantum timesteps. A fixed unitary or fixed CPTP channel acts linearly on density operators; the nonlinear BGK map on arbitrary input probabilities cannot generally be represented exactly by a fixed such channel on a single copy. Investigate reversible fixed-point arithmetic on population registers, or a controlled approximation such as a linearization and block encoding, with explicit ancilla, norm/postselection costs and accuracy. No claim of quantum advantage. The square-root encoding chosen for this milestone might not be the final encoding. Wetting/drying is not solved by the initial dry cells spreading under transport.
