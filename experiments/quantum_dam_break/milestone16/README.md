# Milestone 16 — Conservative nonlinear quantum phase-field interface evolution

## Scope and scientific gate
M15 demonstrated two coherent nonlinear D2Q25 collision–streaming steps but did not solve free-surface physics. The live 3D GitHub phase-field prototype has a collision-only circuit and classical chemical potential. This addition uses the signed fixed-point reversible arithmetic compiler from M6/M8 to implement and execute the actual spatial nonlinear phase evolution. This is a **Cahn–Hilliard finite-difference interface-only prototype**, not D3Q7 LBM, not coupled D3Q19 hydrodynamics, not a physical water-air waterfall. All parameters are nondimensional. Zero velocity, constant mobility, periodic boundaries. See SOURCE_AUDIT.md.

## Equations and circuit
Free energy E = sum[(phi^2-1)^2/4 + |forward differences phi|^2/2], chemical potential mu = phi^3-phi-Laplacian(phi), and time evolution dphi/dt = Laplacian(mu). A=kappa=M=dx=1. We set dt=1/64 in 1D and 1/256 in 3D; these are selected explicit-Euler steps, not an unconditional stability proof. For signed ticks p=S phi and exact integer chemical potential numerator m_i = p_i^3 - S^2 p_i - S^2 Laplacian(p)_i, the edge transfer is J_ij = round((m_i-m_j)*dt/S^2), ties away from zero. Every edge is computed once and contributes -J to its source and +J to its destination, preserving the integer phase sum exactly when output fits. Overflow flags are checked; no clipping or classical repair. In 1D, the edge oracle uses a four-cell stencil. In 3D, the cubic/7-point chemical potential is computed first, then the three oriented edge arrays, then the six-flux conservative update. The physical update is entirely X, CNOT and Toffoli gate computation on signed words; the host gathers fixed neighbour wires and batches basis labels. Large-grid tests use bit-sliced local gate execution, not an allocated full-grid coherent statevector. The independent integer and float solvers validate results and do not feed updates. For a coherent global circuit, inputs remain and intermediate edge/chemical-potential words can be uncomputed in reverse order; 3D global resource estimates count this compute/uncompute schedule, not a transpilation.

The separate four-cell two-step global 1D circuit remaps all gate wires to persistent history registers, uncomputes each timestep's temporary edge registers, and verifies complete reversal on two complex-amplitude components with relative phase i. In a further actual gate execution, CNOT-copy the final *basis word* field into a fresh register and reverse the computation; the original input is retained and the history clears. This is not cloning an arbitrary quantum state and does not remove the input-output entanglement. Unlike stochastic M15 orientation cleanup, the phase evolution is a deterministic function. State preparation is supplied, not synthesized. Qiskit builders are supplied for local oracles and 1D global circuit, not executed here because Qiskit is unavailable. No QPU or speedup claim.

## Executed benchmark results
- 1D: 64 cells, 256 steps each for three precisions and two matched initial-profile families (spinodal cosine and periodic two-interface relaxation). All 1,536 transitions match the independent integer update, exact phase mass, no observed energy increase. Initial field is separately rounded at each precision. Float reference starts from that rounded field. Final spinodal RMSE: 0.05115197, 0.00405019, 0.000173527 at S=256,4096,65536 respectively. Coarse precision completely pins the perturbation. High precision mode gain ~2.4285 vs discrete linear gain 2.4406 (finite-amplitude nonlinear effects expected); this is a small-amplitude sanity check, not continuum convergence. Interface RMSE 0.0281818, 0.00152267, 0.0000618481. Overshoots beyond +/-1 occur.
- 3D: 8x8x8 periodic diffuse droplet, 256 steps at S=65536, nondimensional duration 1. All 256 updates match independent fixed-point reference. Phase sum constant; energy 88.21598 -> 52.57644, no increase steps; final phase RMSE 0.000116327 vs matched float scheme. Positive-phase cells 56 -> 32. phi range [-1.029404,1.069702], so **not a bounded volume fraction**; phase sum conservation is not evidence of separate water mass conservation. No fluid velocity, gravity, surface tension coupling to momentum, wall contact angle or density-ratio validation. 9 VTI snapshots store ASCII CellData: signed phase, chemical potential (derived), reference and error.
- Coherent 1D 4 cells, 2 steps, S=4096: 10,097 logical qubits; 488,576 X/CX/CCX forward gates, two nonzero complex basis amplitudes. Both histories match reference; inverse and copied-output check exact. Copy uses 60 additional qubits and CNOTs; forward/copy/inverse total 977,212 gates. No intermediate measurement/repreparation in this circuit. It is sparse basis permutation simulation, not dense simulation or device run.
- 3D conceptual one-step circuit: 91,861 logical qubits, 39,108,608 X/CX/CCX gates including uncomputation. Local batch simulation executes local oracles, not this complete circuit as one state. These resources are prohibitive on present hardware.
