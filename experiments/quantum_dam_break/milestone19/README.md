# Milestone 19 — focused two-phase dam-release integration

## One research objective
The final objective is a **water–air two-phase dam-break simulation on a quantum computer using LBM**. Do not treat the earlier shallow-water, finite-difference or waterfall studies as independent final objectives. This milestone combines the verified M18 scalar dissipation dilation and closed-wall amplitude transport in one D3Q19/D3Q7 dam-release geometry. It is explicitly **hybrid** and is a low-density-contrast verification stage, not a water–air validation.

## Implemented numerical model
Closed rectangular 32(x) × 4(y) × 16(z) tank, 2048 fluid sites; a smooth heavy-phase column initially at left and floor, light phase outside. The initial condition is a manufactured diffuse rectangular column, not an experimental geometry. Isothermal weakly compressible D3Q19 MRT with Boussinesq reduced gravity `g' = 0.008` in the negative z direction acting on `(clip(phi,-1,1)+1)/2`. Inertial density approximately 1, constant viscosity, no real water/air density or viscosity ratio. Pressure proxy `rho/3`, not validated mechanical phase pressure. Physical lattice units, no SI conversion. D3Q7 signed phase distributions use a conservative Allen–Cahn-style source. Neutral derivative ghost extension at tank walls; stationary halfway bounce-back. No calibrated contact angle. `xi=1.5`, `sigma_model=.003`, `tau_shear=.85` (formal nu=(tau-.5)/3), `tau_phase=.95` (formal mobility=(tau_phase-.5)/4). These choices are experimental, not calibrated.

The signed phase phi=sum g, target profile tanh(d/xi), capillary force mu grad(phi), `mu=3*sigma/(2*xi)*(clip(phi)^3-clip(phi)) - 3*sigma*xi/4*lap(phi)`. The phase sharpening source uses `w_i*(c_i dot n)*(1-clip(phi)^2)/xi`, whose first moment is `cs_phi^2*(1-clip(phi)^2)*n/xi` before trapezoidal MRT prefactor. This gives the intended nominal tanh sharpening scale in the leading-order diffusion balance, rather than the previous M18 source's factor twice as large. The scheme is CAC-style, not a reproduction of a published high-density-ratio method. Clipping is used only in force/source constitutive terms, **not** to overwrite the conserved phase distribution. The phase bounds fail; formal fraction and its moments are diagnostics, not bounded physical liquid volume or COM.

## Quantum operations and classical dependencies
`collision.py` constructs an orthonormal polynomial moment basis; hydro mass and momentum rows are conserved, trace mode rate 1, five deviatoric stress modes rate 1/tau, higher nine modes rate 1.2. D3Q7 only phase mass conserved, other six use 1/tau_phase. For each nonconserved moment `d=m-meq`, prepare sign-split rail amplitudes sqrt(1-|d|/B), sqrt(|d|/B), with B=.25 (reject out of range). This pure preparation shares relevant diagonal probabilities with the original mixed sign-split encoding, but does not claim the same off-diagonals. Actual four-qubit CRY/CX damping unitary from M18 executes on a batch of complex statevectors, with rail SWAP for negative lambda. Readout uses exact rail probabilities or seeded binomial samples. Conserved modes bypass quantum dissipation and retain exact classical values. Sources use MRT trapezoidal factor `I-S/2`. The reference uses a separately implemented population-space matrix update and slice-based push streaming, but shares governing equations and moment basis: agreement validates implementation, not physical correctness.

Hydro and phase fields are reconstructed and amplitude encoded separately for closed-wall transport using direct fully-controlled X gate sequences from M18; exact statevector readout is used after each transport. Classical calculations include moment transforms, equilibrium, forces, encoding parameters, preparation and all reconstruction. This is not a coherent end-to-end quantum solver; no hardware execution, shot-efficient streaming readout, advantage or full native transpilation. `qiskit_mode` optional circuit export with RY preparation; optional test skipped when Qiskit is absent. Finite-shot trajectories sample only relaxation-stage readout and use exact amplitude transport, one seeded trajectory per budget, not statistical confidence intervals. 21 mode circuits per node per step = 4,128,768 mode updates per 96-step trajectory; naive 4096 shots per mode costs 16,911,433,728 circuit shots before state preparation/readout costs for streaming. 16 and 14 qubit transport registers, 254808 and 62144 logical MCX gates per step respectively, not native physical gate counts. The modes use separate 4-qubit circuit simulations, not 4 qubits for the whole problem.

## Results and acceptance gates
Five 96-step runs: exact quantum-subroutine hybrid, independent population-space reference, zero gravity control, 256-shot and 4096-shot sampled dissipation. See `results/report.json`, `diagnostics.csv`, `history.npz`, 7 VTK files, plots and GIF. Exact hybrid phase RMSE 4.46e-14 against same-model reference; max population discrepancy 9.55e-14. Local mass/phase error <4.5e-15; momentum source error <1.2e-16, global impulse balance (wall impulse plus total forcing) <2.5e-12. Global mass and signed phase conservation within floating error. Gravity response compared with zero-gravity run; phase moment x increases 4.958→5.342 and z decreases 4.878→4.222 with gravity; no-gravity x 4.935 and z 4.850. This is not calibrated front speed or physical COM because phase bounds fail. Maximum phi 1.1267; final 482 of 2048 cells outside [-1,1] using 1e-10 tolerance. Report this as FAILED physical bound, not a passing water-air test. Finite-shot phase RMSE 0.00403 at 256 and 0.00110 at 4096. 15 new tests pass, optional Qiskit test skips. Historical full regression not rerun for M19; M18 source/results preserved and focused M18+M19 regression in results. No remote changes.

## Strict next development gate
Do not extend to waterfall or other unrelated model. Use one authoritative two-phase dam-break architecture. First reproduce a validated high-density-ratio pressure-based two-phase LBM reference (e.g. Fakhari et al. 2017), with boundedness, mass/density/viscosity, static droplet pressure and spurious currents, and experimental dam-break front/height. Audit newer remote phase-field/variational branches for actual circuit execution and encoding compatibility. Integrate only independently verified mechanisms into this reference, quantify finite-shot and state-preparation costs, then demonstrate a small coherent or explicitly hybrid end-to-end circuit and hardware-feasible case. The present solver is a verification bridge, not the final physical model.
